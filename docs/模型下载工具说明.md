# PeachOCR 模型预下载工具

工具位置：`tools/download_models/`

本工具基于 [Sdcb.OpenVINO.PaddleOCR.Models.Online](https://www.nuget.org/packages/Sdcb.OpenVINO.PaddleOCR.Models.Online) 实现，通过 `OnlineFullModels` API 从 Paddle 官方源下载 PP-OCR 模型。下载后的模型文件会被自动复制到项目输出目录并随程序一同打包（由项目 `.csproj` 中的 `models\\**\\*.*` 规则保证）。

## 支持的模型

| 模型 | 格式 | 说明 | 目录 |
|------|------|------|------|
| PP-OCRv6 Small | ONNX | 默认推荐模型，精度和速度均衡 | `models/ch_PP-OCRv6/` |
| PP-OCRv4 | Paddle (.pdmodel) | 兼容 PP-OCRv5 运行，共享同一套模型 | `models/ch_PP-OCRv4_det/`、`models/ch_PP-OCRv4_rec/`、`models/ch_ppocr_mobile_v2.0_cls/` |

> 说明：Sdcb 库对 v4/v5 仅支持 Paddle 格式，对 v6 才支持 ONNX 格式。

## 用法

在项目根目录 `d:\Code\CSharp\PeachOCR` 下执行：

```powershell
# 下载全部模型（v4 + v6）
dotnet run --project tools/download_models -- --all

# 下载指定模型
dotnet run --project tools/download_models -- --model v4
dotnet run --project tools/download_models -- --model v6

# 指定自定义输出目录（默认：项目根目录的 models/）
dotnet run --project tools/download_models -- "D:\SomePath\models"
```

首次运行时会联网下载并缓存。再次执行时会检测缓存，不再重复下载。

## 新增模型

当 Sdcb.OpenVINO.PaddleOCR 后续版本支持新的 `OnlineFullModels` 模型时，只需在 `Program.cs` 的 `switch` 中添加对应的下载逻辑：

```csharp
case "v7":
    Settings.GlobalModelDirectory = Path.Combine(targetDir, "ch_PP-OCRv7");
    await OnlineFullModels.ChineseV7.DownloadAsync();
    break;
```

并更新 CLI 选项与项目 `OcrBatchProcessor.cs` 中的模型分派即可。

## 清理缓存

如需要重新下载（例如模型更新后），先删除对应的模型目录再运行：

```powershell
Remove-Item -Recurse -Force models\ch_PP-OCRv6
dotnet run --project tools/download_models -- --model v6
```
